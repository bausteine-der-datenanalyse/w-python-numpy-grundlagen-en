10.1 Task 1: Movie Database

In the first task, we want to analyze fictional data for movie ratings. The dataset is simplified and contains the following columns:

  1. Movie ID
  2. User ID
  3. Rating

Here is the dataset:

10.2 Exercise 2 - Cryptography - Caesar Cipher

In this exercise, we want to both encrypt and decrypt text.

Each character is assigned a numerical value via the so-called ASCII table.

For simplicity, the following code for converting letters to numeric values and back is already provided. We will also limit ourselves to texts with lowercase letters.

Your task is now to modify the numeric values.

First, we want to apply a simple Caesar cipher. In this cipher, all letters are shifted by a certain number of positions. For example, if the shift value is “1”, an ‘a’ becomes ‘b’, ‘m’ becomes ‘n’, and so on. If the shift value is “4”, an ‘a’ becomes ‘e’ and ‘m’ becomes ‘q’. The shift is cyclic, meaning that with a shift of 1, ‘z’ becomes ‘a’.

import numpy as np

# Function that converts a letter to its ASCII value
def letter_to_ascii(c):
    return np.array([ord(c)])

# Function that converts an ASCII value to the corresponding letter
def ascii_to_letter(a):
    return chr(a)
1. First, think about how to express this cyclic shift mathematically (Hint: modulo calculation)
Solution

\[ \textrm{ASCII}_{\textrm{shifted}} = (\textrm{ASCII} - 97 + \textrm{Shift}) \textrm{ mod } 26 + 97\]

2. Write code that converts all characters using a loop.

First, all characters should be converted to ASCII codes. Then, the formula is applied to the numeric values, and finally, in a third loop, all values are converted back to letters.

Solution 
import numpy as np

# Function that converts a letter to its ASCII value
def letter_to_ascii(c):
    return ord(c)

# Function that converts an ASCII value back to the corresponding letter
def ascii_to_letter(a):
    return chr(a)

plaintext = "abrakadabra"
shift = 3

converted_text = []
shifted_numbers = []
encrypted_text = []

# Convert letters to ASCII
for letter in plaintext:
    converted_text.append(letter_to_ascii(letter))
print(converted_text)

# Apply shift formula
for number in converted_text:    
    shifted = (number - 97 + shift) % 26 + 97
    shifted_numbers.append(shifted)
print(shifted_numbers)

# Convert ASCII back to letters
for number in shifted_numbers:    
    encrypted_text.append(ascii_to_letter(number))
print(encrypted_text)

[100, 101, 117, 100, 110, 100, 103, 100, 101, 117, 100]
['d', 'e', 'u', 'd', 'n', 'd', 'g', 'd', 'e', 'u', 'd']

Solution 
import numpy as np

# Function that converts a letter to its ASCII value
def letter_to_ascii(c):
    return ord(c)

# Function that converts an ASCII value back to the corresponding letter
def ascii_to_letter(a):
    return chr(a)

shift = 3

converted_text = []
encrypted_numbers = []
decrypted_text = []

for letter in encrypted_text:
    converted_text.append(letter_to_ascii(letter))
print(converted_text)

converted_text = np.array(converted_text)
encrypted_numbers = (converted_text - 97 - shift) % 26 + 97
print(encrypted_numbers)

for number in encrypted_numbers:    
    decrypted_text.append(ascii_to_letter(number))
print(decrypted_text)
